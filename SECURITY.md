# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by emailing `keelmatrix@gmail.com` or opening a private GitHub security advisory. Do not disclose vulnerability details in a public issue, pull request, package comment, or forum post.

Include the affected package version, target framework, a minimal reproduction, impact, relevant baseline or schema shape with proprietary values removed, and any suggested mitigation. Do not include secrets or private customer data.

## Supported Versions

The latest published stable version receives security fixes. Pre-release versions are useful for evaluation and may change; upgrade to the latest stable release when available.

## Scope

Security reports should concern the library, its package contents, unsafe parsing/resource behavior, accidental network or data collection, or a release artifact. Ordinary compatibility questions and usage bugs belong in the normal issue tracker after sensitive details have been removed.
